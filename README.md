### Senent

## Description
In Ancient Egyptian, ''Senet'' meant "passing," as in passing on to the afterlife. Indeed, many of our records of Senet were found in tombs. Some of the oldest boards date back to the Middle Kingdom (~ 2050 - 1710 BC). The game was first referenced in tomb paintings around the 25th century BC. The game continued to be played for a long time, until it faded from use around the time Egypt came under Roman control (30 BC). For a game that existed for such a long time, it is not so surprising that we have found so many variants of boards.
